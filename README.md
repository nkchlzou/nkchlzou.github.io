# Changliang Zou — Academic Homepage

A self-contained, responsive static homepage for GitHub Pages.

## Files

- `index.html`: all page content and styling; no build step or external font/script/CDN.
- `portrait.jpg`: the owner-supplied photograph, unchanged. The homepage uses a CSS display crop; the full photo remains available.
- `.nojekyll`: tells GitHub Pages to serve the static site without Jekyll processing.

## Publish

1. Create a **public** repository named `YOUR-USERNAME.github.io`, replacing `YOUR-USERNAME` with your actual GitHub username in lowercase.
2. Upload the **contents** of the `website` folder to the root of the `main` branch. Do not upload the ZIP or the enclosing folder.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch → main → /(root) → Save**.
5. Visit `https://YOUR-USERNAME.github.io/` after deployment succeeds.

The ZIP package includes a separate Chinese guide (`使用说明.html`) and a local, form-based editor (`维护工具.html`). They do not need to be uploaded.

## Content and scope

Migrated on 2026-09-13 from the owner's public page:
https://sites.google.com/site/nkchlzou/home

The page preserves the profile, contact details, short bio, research interests, teaching, and all 41 selected publications (22 journal papers; 19 conference papers) in their original order. Whitespace, stray quotation marks, punctuation spacing, and page-range dashes have been tidied. Bibliographic metadata, years, and acceptance statuses have **not** been independently re-verified or updated. Original Chinese-homepage and Google-Scholar URLs are retained as external links; their destination pages are not copied. No publication PDF/code links, positions, or research claims have been invented.

This is a one-time migration, not synchronization with Google Sites. Future updates must be made to this site.
